# ADR 0001 — Record architecture decisions

- Status: accepted
- Date: 2026-10-29

## Context

This is a learning + portfolio microservices project with many deliberate design choices.
Future-me (and reviewers) need to know *why* each choice was made, not just what it was.

## Decision

We record significant architectural decisions as short Markdown ADRs in `docs/adr/`,
numbered sequentially. Each ADR states context, the decision, and consequences
(trade-offs). The locked Phase 0 design is captured across ADRs 0002+.

## Consequences

- Decisions are reviewable in pull requests alongside code.
- The root README's "Design decisions" section links here instead of duplicating detail.
